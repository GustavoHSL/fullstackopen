Exercícios e projetos da **Part 3** do curso Full Stack Open,

## 🧠 Principais conceitos

- Criação de servidor HTTP com **Node.js**
- Rotas e middlewares com **Express**
- API REST — verbos HTTP, status codes e estrutura de recursos
- Integração com **MongoDB** via Mongoose
- Variáveis de ambiente com **dotenv**
- Validação de dados com Mongoose schemas
- Deploy na nuvem com **Render** ou **Fly.io**
- Qualidade de código com **ESLint**
