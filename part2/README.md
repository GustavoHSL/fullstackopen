# Part 2 — Comunicação com servidor

Exercícios e projetos da **Part 2** do curso Full Stack Open,
com foco em renderização de coleções, formulários e integração com APIs externas.

> Nesta parte o React começa a conversar com o mundo — consumindo e
> enviando dados para servidores via axios e json-server.

---

## 📚 Conteúdo

| Módulo | Tópico |
|--------|--------|
| 2a | Renderizando coleções e módulos |
| 2b | Formulários controlados |
| 2c | Buscando dados do servidor |
| 2d | Alterando dados no servidor |
| 2e | Adicionando estilos ao React |

## 🗂 Estrutura
```
part2/
├── courseinfo/      # Continuação do app de informações do curso
├── phonebook/       # Agenda telefônica com CRUD e json-server
└── countries/       # Busca de países consumindo API externa
```

---

## 🧠 Principais conceitos

- Renderização de listas com `.map()` e uso correto de `key`
- Formulários controlados com `useState`
- Requisições HTTP com **axios** — `GET`, `POST`, `PUT`, `DELETE`
- Efeitos colaterais com `useEffect`
- Comunicação com **json-server** como backend fake
- Consumo de API REST externa (RestCountries)
- Feedback visual ao usuário com notificações de erro e sucesso
